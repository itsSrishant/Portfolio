The 12 WebP files in this directory are converted from AI-generated images
that reproduce Marvel's Black Panther character design (Marvel copyright/
trademark), not an original character. They exist only so the cinematic
intro's compositing/animation mechanism could be built and demoed locally.

**Before this site is ever deployed publicly, every file in this directory
must be replaced with original, non-infringing artwork** — same filenames,
same 6-beat sequence (rest → awakening → gesture → energy → dissolve →
curtain), same 1408×768 desktop / 800px-wide mobile dimensions. See
`docs/superpowers/specs/2026-08-02-purple-cinematic-intro-design.md` for
the full story-beat description each frame needs to convey.

This directory is `.gitignore`d (except this file) specifically so the
placeholder art is never accidentally committed.
